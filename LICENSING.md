not relicense third-party data, and nothing in this repository is relicensed
automatically from any other repository.

## Rights holder

The current copyright holders are the contributors recorded in Git history
(substantially all by Kube Kubow; AI-assisted commits are marked with
`Co-authored-by` trailers). A transfer of economic rights to the Kefer
Astrology nonprofit is **planned but not yet executed**; until a written
assignment exists, the notice above remains accurate and must not be changed
to name the nonprofit.

## Separation from proprietary components

This repository must contain only material intended for public, MIT-licensed
distribution. Advanced school definitions, interpretation texts, original
research, the Sabian symbol text and graphical sources belong in private
repositories and must not be added here.
